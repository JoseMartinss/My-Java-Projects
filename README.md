## 💻 Como Executar os Projetos Localmente

### Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- [JDK (Java Development Kit)](https://www.oracle.com/java/technologies/downloads/) instalado e configurado nas variáveis de ambiente.
- [Git](https://git-scm.com/) instalado.

### Passo a passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. **Acesse o diretório do repositório:**
   ```bash
   cd SEU-REPOSITORIO
   ```

3. **Compilar e executar um arquivo específico:**
   ```bash
   # Compilar
   javac src/caminho/do/arquivo/NomeDoArquivo.java

   # Executar
   java -cp src caminho.do.arquivo.NomeDoArquivo
   ```
